Connect to Google Sheets

  1. Open your Google Sheet → Extensions → Apps Script
  2. Paste the StockMF_Connected.gs file → Save → Run setupAll()
  3. Click Deploy → New Deployment → Web App
  4. Execute as: Me · Who has access: Anyone
  5. Copy the Web App URL and paste below

Your URL is stored only in this browser's localStorage — never sent anywhere except directly to your own Google Apps Script.
